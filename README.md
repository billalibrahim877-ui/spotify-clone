# Spotify Clone

A simple Spotify-inspired landing page built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve it with a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Features

- Dark Spotify-inspired layout
- Responsive sidebar + main content + player bar
- Playlist and music cards
- Interactive player updates when tracks are selected
- Mobile-friendly design
